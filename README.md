# Mobile Gateway

Мобильное Android-приложение на Python для удалённого взаимодействия с сервером: получения актуальных данных, отправки управляющих команд, просмотра фотографий и видеопотока с камер видеонаблюдения.

## Основные возможности

- **Двусторонний обмен данными**: получение статусов и информации с сервера (GET) и отправка пользовательских параметров или команд (POST).
- **Видеонаблюдение и медиа**: воспроизведение живого видеопотока с камер (`flet-video`) и отображение статичных снимков.
- **Современный интерфейс**: кроссплатформенный UI на базе Flet/Flutter с поддержкой светлой и тёмной темы.
- **Асинхронная работа**: сетевые запросы выполняются без блокировки интерфейса.

## Технологический стек

- **Python**: 3.14+ (см. `pyproject.toml`)
- **UI-фреймворк**: [Flet](https://flet.dev/) 1.x
- **Мультимедиа**: `flet-video`
- **HTTP-клиент**: [HTTPX](https://www.python-httpx.org/)
- **Конфигурация**: `python-dotenv` + переменные окружения
- **Управление зависимостями**: Poetry

## Быстрый старт

### 1. Установка зависимостей

```bash
git clone <repo-url>
cd MobileGateway
poetry install
```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта (при необходимости используйте `.env.sample` как основу) и укажите параметры подключения:

```env
API_URL=http://192.168.1.100:8000
API_TIMEOUT=10.0
STREAM_URL=
SNAPSHOT_ENDPOINT=/camera/snapshot
API_TOKEN=
```

Параметры читаются в `src/core/config.py`.

### 3. Запуск

Локальный запуск на ПК:

```bash
poetry run flet run main.py
```

Тестирование на Android (ПК и телефон должны быть в одной Wi-Fi сети, на телефоне должно быть установлено приложение Flet):

```bash
poetry run flet run --android main.py
```

## Сборка APK для Android

На Windows для сборки должен быть включён «Режим разработчика».

```bash
poetry run flet build apk
```

Готовый файл появится в директории `build/apk/`.
