# Mobile Gateway

Мобильное Android-приложение на Python для удалённого взаимодействия с сервером: получения актуальных данных, отправки управляющих команд, просмотра фотографий и видеопотока с камер видеонаблюдения.

## Основные возможности
* **Двусторонний обмен данными**. Получение статусов и информации с сервера (GET) и отправка пользовательских параметров или команд (POST).
* **Видеонаблюдение и медиа**. Воспроизведение живого видеопотока с камер (`flet-video`) и отображение статичных снимков в высоком качестве.
* **Современный интерфейс**. Кроссплатформенный UI на базе Material Design с автоматической поддержкой светлой и тёмной темы смартфона.
* **Асинхронная работа**. Сетевые запросы выполняются в фоне без блокировки и зависания интерфейса.

## Технологический стек
* **Язык программирования**: Python 3.10+
* **UI-фреймворк**: [Flet](https://flet.dev) (движок Flutter)
* **Мультимедиа**: `flet-video`
* **Сетевой клиент**: [HTTPX](https://python-httpx.org) (асинхронные HTTP-запросы)

## Быстрый старт (разработка на Windows)

### 1. Клонирование и установка зависимостей
Создайте виртуальное окружение и установите необходимые пакеты:

```bash
git clone https://github.com
cd mobile-gateway

python -m venv venv
venv\Scripts\activate

pip install flet flet-video httpx
```

### 2. Настройка подключения
Откройте основной файл проекта (например, `main.py`) и укажите актуальный адрес вашего сервера:

```python
API_URL = "http://192.168.1.X:8000"  # Локальный IP или домен сервера
STREAM_URL = "rtsp://..."            # Ссылка на видеопоток (при необходимости)
```

### 3. Запуск и тестирование
* **Локальный запуск на ПК**:
  ```bash
  flet run main.py
  ```
* **Тестирование на Android-смартфоне** (ПК и телефон должны быть в одной Wi-Fi сети, на телефон должно быть установлено приложение Flet):
  ```bash
  flet run --android main.py
  ```

## Сборка APK для Android
Для компиляции установочного файла на Windows (должен быть включён «Режим разработчика» в параметрах системы):

```bash
flet build apk
```
Готовый файл появится в директории `build/apk/`.
