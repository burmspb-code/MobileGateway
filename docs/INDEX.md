# Карта проекта

Заполни этот файл под конкретный проект. Это единственное место для правил проекта: `AGENTS.md` намеренно универсален.

## Правила проекта

- Тесты: `poetry run pytest -q`
- Источник истины: _ветка / файл / сервис_.
- Запреты и важные договорённости: _что трогать нельзя, что делать только по фразе_.

## Карта документации

| Файл | Когда читать |
|---|---|
| `КОМАНДЫ.md` | шпаргалка фраз для пользователя |
| `docs/workflow.md` | сценарии фраз-триггеров |
| `docs/topics/INDEX.md` | выбор и переключение тем |
| `docs/decisions.md` | почему принято то или иное решение |
| `docs/handoff.md` | быстрая сводка активной темы |
