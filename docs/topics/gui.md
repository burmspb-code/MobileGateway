## Цель
Разработать графический интерфейс MobileGateway.

## Решено
- Первый тестовый образец — APK с минимальным интерфейсом: две кнопки «Старт» и «Стоп», без сервера/камеры/авторизации; цель — подтвердить сборку, установку и работу UI на Android.
- После успешного smoke-теста двигаться инкрементами: настройки подключения, проверка связи с сервером, затем реальные команды/данные.
