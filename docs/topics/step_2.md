## Цель
Реализовать по `docs/step_2.md` экран настроек подключения, локальное сохранение параметров и проверку связи с сервером, не ломая тестовые Start/Stop.

## Решено
- Шаг 2 выделен в отдельную тему; темы «Старт» и «Разработка GUI» закрыты 2026-11-25.
- Настройки хранить через `page.client_storage`; токен не логировать и не показывать в ошибках UI.
- Проверку связи делать конфигурируемой: `API_URL` + `HEALTH_ENDPOINT`. При отсутствии реального сервера для отладки UI использовать локальную заглушку `/health`.

## Сделано
- Создана карточка темы, добавлена строка в `docs/topics/INDEX.md`.
- `docs/handoff.md` указывает на эту тему; план работ принят из `docs/step_2.md` (шаги 1–10).

## Блокировка
Не зафиксирован реальный адрес сервера и нужен ли токен. Для начала работ достаточно локальной заглушки, финальную проверку сделать на реальном адресе.

## Следующий шаг
Уточнить контракт `GET {API_URL}{HEALTH_ENDPOINT}` и подготовить модель настроек (`docs/step_2.md`, шаги 1–2).
