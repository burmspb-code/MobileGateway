# Команды — шпаргалка пользователя

Фразы регистронезависимы: `НАЧИНАЕМ РАБОТУ!`, `начинаем работу` и `Начинаем Работу` — одно и то же. Отправляй фразу отдельным сообщением. Знаки `!` и `.` на конце не важны.

## Темы

| Что написать | Что получишь |
|---|---|
| «Начинаем работу» | Если есть незакоммиченные хвосты — предыдущая тема фиксируется коммитом; затем список тем на выбор |
| «Меняем тему» | Текущая тема фиксируется коммитом; список тем; выбранная тема записывается в `docs/handoff.md`, и работа продолжается сразу |
| «Список тем» | Только показать реестр — без коммита и без запуска работы |
| «Архив» | Показать закрытые темы; можно «Посмотреть» или «Возобновить» |
| «Тема закрыта» | Тема уходит в архив, делается коммит, спрашивается: новая тема или из существующих |

## Завершение работы

| Фраза | Действие |
|---|---|
| «Работа закончена» | Карточка обновляется, связи дополняются, делается коммит. Тема остаётся открытой |
| «Работу закончил» | То же самое |
| «Закончил работу» | То же самое |

Закрывает тему **только** «Тема закрыта». «Работа закончена» — просто конец сессии.

## Продолжение без фразы

Если тема уже выбрана (в том числе через «Меняем тему»), просто открой новую сессию. Ассистент прочитает `docs/handoff.md` и продолжит с неё. Повторять «Начинаем работу» **не нужно**.

«Начинаем работу» нужна только когда хочешь увидеть список и выбрать тему заново.

## Выбор из списка

После показа списка можно ответить:

- номером — `1`;
- названием или его частью — `почта`;
- если несколько тем подходят — ассистент уточнит.

## Дополнительные команды

- `/docs` — показать карту документации и спросить, что нужно.
- `/docs почта` — прочитать только нужный документ по теме.

## Примеры

```text
Начинаем работу
Меняем тему
Работа закончена!
НАЧИНАЕМ РАБОТУ
1
почта
```

Последние две строки — пример выбора темы после показа списка.
